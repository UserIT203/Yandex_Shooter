## 📖 Описание проекта
**Yandex Shooter** – это 2.5D рогалик, разработанный специально для платформы Яндекс Игры. Проект ориентирован на высокую производительность, отзывчивое управление и увлекательный геймплей, оптимизированный для стабильной работы на широком спектре устройств, включая мобильные браузеры и ПК с низкими системными требованиями.

## 🛠 Использованные технологии
Проект построен с использованием современного стека технологий Unity, обеспечивающего чистую архитектуру и высокую производительность:

- **Unity & C#**: Основная среда разработки и язык программирования.
- **Yandex Games SDK**: Интеграция для авторизации игрока, облачных сохранений, показа рекламы (Interstitial/Rewarded) и работы с лидербордами.
- **Zenject**: Внедрение зависимостей (DI) для обеспечения слабой связности компонентов, модульности и упрощения тестирования.
- **DOTween**: Плавные и производительные анимации пользовательского интерфейса (UI) и игровых объектов.
- **Object Pooling**: Кастомная реализация пула объектов с использованием высокопроизводительных коллекций .NET для минимизации аллокаций памяти (GC spikes) и уменьшения размера финального билда.
- **Unity Profiler**: Оптимизация производительности (CPU, GPU, память) для достижения стабильных 60 FPS на WebGL.
- **Timeline**: для создание катсцен

## ✅ Проделанная работа
- **Геймплей**: Реализована основная механика шутера (передвижение, стрельба, система здоровья, ИИ и поведение противников).
- **Катсцены**.
- **Интеграция с платформой**: Полная интеграция Yandex Games SDK (инициализация, авторизация, облачные сохранения, рекламные интеграции).
- **Архитектура**: Рефакторинг кодовой базы с внедрением Zenject для масштабируемости и удобства командной разработки.
- **Оптимизация**: 
  - Внедрение пула объектов для пуль, врагов и визуальных эффектов (VFX).
  - Настройка Addressables для разделения бандлов и быстрой подгрузки ресурсов.
  - Профилирование и устранение узких мест (bottlenecks) в Unity Profiler.
- **Аудио и баланс**: Настройка звукового сопровождения (SFX, музыка) и тонкая балансировка игровых параметров (урон, скорость, здоровье) для обеспечения честного и увлекательного игрового опыта (см. коммиты "Balance And Sound").
- **UI/UX**: Создание адаптивного пользовательского интерфейса с анимациями через DOTween.
